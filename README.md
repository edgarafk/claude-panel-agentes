# panel-agentes

Panel que se abre solo cuando hay agentes trabajando: muestra qué hace cada uno (tipo, tarea, estado, última acción, resultado) y una guía de cada tipo de agente. Se cierra 15 s después de que termine el último. Comando manual: `/agentes`.

## Instalar

Sube esta carpeta a un repositorio de GitHub y, en una terminal con Claude Code:

```
/plugin install panel-agentes --marketplace edgarafk/claude-panel-agentes
```

Responde `y` para añadir el marketplace y elige el ámbito **user** para que funcione en todas tus sesiones.
